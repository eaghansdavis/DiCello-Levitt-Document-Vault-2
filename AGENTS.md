# Contributor Guidance

## Scope
These instructions apply to the entire repository unless superseded by a nested `AGENTS.md` file.

## Working agreements
- Run `npm test` after modifying JavaScript files.
- Prefer `pnpm` when installing dependencies.
- Confirm with stakeholders before adding new production dependencies.

## Repository conventions
- Keep documentation up to date when adding new components or services.
- Use clear, action-oriented commit messages.
- Favor small, focused pull requests with passing tests.
